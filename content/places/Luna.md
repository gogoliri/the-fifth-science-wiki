# Luna

**Type:** [[Aerth]]'s moon.
**Era of appearance:** Used as a yardstick in the ~2641 A.L. Pasternak scenes.

## Summary
Referenced only as a unit of size: the particle collider [[K. Pasternak]] builds for [[The First Wanderer]] is described as larger than the Aerth-Luna diameter — an object that, if assembled at [[Aerth]], would physically intersect the moon. This makes Luna a scale marker, not a setting.

## Appearances
- [[Ch. 03 — For Every Dove a Bullet]]: Size reference for the 5-[[Churten]] collider.

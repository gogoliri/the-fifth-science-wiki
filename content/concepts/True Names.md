# True Names

## Summary
Per the [[Lantern]], every object in the universe (a planet, an atom, a person, Time itself) has a **true name**: "the name the universe recognises that thing by." A true name is not a label but a complete description. It "contains all the information one might want to know about an object. Its age, for example. Its form. And the time when it will die." Lanterns learn true names, and learn to say them, while awake in [[Etherspace]], where all events occur at once.

## In the book
- [[Ch. 08 — The Lantern]]: [[Sandansk]] has 89 names (Sandansk, Ik'Quoeb, No Mo5, ...), none of them its true name. [[Beomus]]'s true name is Shat'Nusemit, which marks him as a good man due to die of a heart attack in 3 years, 1 month and 13 days. The lantern has a true name of its own but declines to discuss it. *"If you knew Time's true name you would understand that it is a bread loaf already baked."*

## Real-world grounding
- The folk/magical tradition of true names (e.g. Le Guin's Earthsea, Kabbalistic names, Rumpelstiltskin) recast as a *physical* fact: the name is a compressed four-dimensional description of the object across its whole history.
- Block-universe eternalism: a thing's death date is as much a property of it as its form.

## Open questions
- Can a true name be spoken *to* something to affect it, as in the folk tradition, or is it read-only?
- Does knowing your own true name change anything? The narrator refuses to hear his.
